## Goal

Replace the deterministic body of the existing `vsdb.generateSampleData` command (table nodes)
with an AI-driven flow: values generated by the AI **work model** from table/column name
semantics, `id_<table>` and `created_at` (and identity/nextval columns) never inserted,
INSERT-only-for-this-table validation (all-or-nothing), execution via one
`adapter.runQuery` call, summary toast.

## Discussion

### 2026-08-24 · planner · unic/unic-smart
Atomicity: send all INSERTs as ONE multi-statement string to a single `adapter.runQuery` call —
node-postgres simple-query protocol runs multi-statement strings in an implicit transaction
(all-or-nothing). Do NOT loop per statement. AI role is work ONLY (`cfg.models.work.modelId`) —
hard constraint from §7. N cap 1..100 for the AI path (old 1000 cap dropped; cost). Validation
mirror: inverted `isReadOnlySql` philosophy — whitelist INSERT INTO this exact quoted/qualified
table, reject everything else including fences/explanatory text.
